🔍 How to View Your Click Tracking Data in Google Analytics

  1. Access Google Analytics: Go to analytics.google.com and sign in
  2. Select Your Property: Choose your PrideMap property (G-3Y7XDQTWMR)
  3. Navigate to Events: Go to Reports → Engagement → Events
  4. View Click Data: You'll see all the click events we're tracking below
  5. Create Custom Reports: Use the data to create custom reports and dashboards

📈 What We're Tracking

Event Card Clicks
When users click on event cards to view full details. Includes event name and ID for detailed analysis.
Filter Interactions
All filter button clicks including "All", "This Week", "Today", "Party", "Social", "Workshop".
Tag Filter Operations
Tag selection/deselection, opening/closing tag filter, clearing all tags, applying filters.
Map Marker Clicks
When users click on map markers and popup buttons to view event details.
Action Button Clicks
"Get Tickets" and "Website" button clicks with associated event names.
External Link Clicks
Newsletter signup links and venue address links to Google Maps.
Navigation Actions
Back button clicks, mobile view toggles, and other navigation elements.
Map-to-Detail Navigation
When users navigate from map popups to detailed event views.

📊 Key Metrics to Monitor

Event Engagement: Which events get the most clicks? This helps identify popular event types and venues.
Filter Usage: Which filters are most popular? This shows user preferences and search behavior.
Conversion Tracking: How many users click "Get Tickets" or "Website"? This measures actual engagement with events.
Mobile vs Desktop: Track how users interact differently on mobile devices vs desktop.
Map vs List View: Understand user preference for viewing events on map vs list format.

🔧 Custom Reports You Can Create

Event Popularity Report:
• Filter by Event Category: "Event Card"
• Group by Event Label (event names)
• Sort by Event Count (descending)
Filter Usage Report:
• Filter by Event Category: "Filter"
• Group by Event Label (filter types)
• Analyze over time to see trends
Conversion Funnel Report:
• Event Card Clicks → Event Detail Views → Action Button Clicks
• Track conversion rates from discovery to action
Mobile vs Desktop Comparison:
• Segment by Device Category
• Compare interaction patterns between mobile and desktop users

🚀 Optimization Opportunities

  • Popular Events: If certain events get more clicks, consider featuring them more prominently
  • Filter Optimization: If "This Week" is popular, consider making it the default view
  • Mobile Experience: If mobile users have lower conversion rates, optimize the mobile interface
  • Tag Usage: If certain tags are rarely used, consider removing or reorganizing them
  • Map vs List: If users prefer one view over the other, consider making it the default
  • Action Buttons: If "Get Tickets" has low click rates, consider making it more prominent
